# Security policy

## Supported versions

Only the latest public release is supported. The current release is 0.5.0.

## Report a vulnerability

Please do not post access tokens, chat exports, private URLs, screenshots containing account data, or exploit details in a public issue. Use the repository's **Security → Report a vulnerability** option to send a private report. Include the affected release and a short description of the impact. Remove or redact any personal data.

If private reporting is unavailable, open a public issue with the title `Private security report requested` and no sensitive details; maintainers can enable a private channel before you share technical information.

## Scope

ChatGPT Companion runs in the browser on `chatgpt.com`, handles account conversation data, and can perform permanent chat deletion when requested. Local full-text records are not encrypted by the extension. Please report issues that could expose data beyond the user's browser profile, misuse a ChatGPT session, or cause an account action without the user's intent.

The project has not had an independent security audit. Open-source availability is not a guarantee that a release is free of vulnerabilities.
